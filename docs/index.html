コンテナバインドGASによる相対解決

スプレッドシート自身にGASを紐づけることで、SPREADSHEET_ID と ROOT_FOLDER_ID の手動設定が一切不要になります。ルートフォルダごと別階層へ移動しても動作し続けます。

箱フォルダ（{box_id}）を切るメリット

  • 一括共有終了: Drive上で箱フォルダごとゴミ箱へ移すだけで、中の複数ファイルをまとめて無効化できます。
  • 一括ダウンロード: 「もらう箱」で集めた写真を、箱主はDrive上でフォルダごとZIP一括ダウンロードできます。
  • 同名衝突の回避: Driveは同一フォルダ内の同名ファイルを別 file_id として保持するため上書きされません。

配置時の注意ルール

管理用スプレッドシートはマイドライブ直下に置かず、必ず専用ルートフォルダ（例：hakonushi）の中に配置してください。またスプレッドシート単体を別フォルダへ移動しない運用にします。
